# Inventory service API index

Framework: **FastAPI** · App factory: `inventory_app.app:create_app` · Default port: `8091`

Interactive OpenAPI when the service is running: `GET <BASE_URL>/docs` (generated by FastAPI from routes/schemas). This Markdown captures implementation paths and flows OpenAPI does not.

Auth: **Not explicitly enforced in current implementation** (all listed routes are callable without JWT/API key in code).
